# Contributing Guidelines

Thank you for your interest in contributing to Awesome Developer Tools!

## Adding a Tool

Please ensure your pull request follows these guidelines:

- **Search previous suggestions** before making a new one to avoid duplicates.
- Make an individual pull request for each suggestion.
- Use the following format: `[Tool Name](link) - Description.`
- New categories or improvements to the existing categorization are welcome.
- Keep descriptions short and simple, but descriptive.
- Start the description with a capital letter and end with a period.
- Check your spelling and grammar.
- The tool should be well-maintained and have a clear use case for developers.
- The pull request should have a useful title and include a link to the tool and why it should be included.

## Updating an Entry

- If a link is broken or a project has moved, please submit a PR to fix it.
- If a project is no longer maintained, it may be removed.

## Quality Standards

To be included, a project should meet the following criteria:

- Actively maintained (commits within the last 12 months).
- Has clear documentation or a README.
- Solves a real problem for developers.
- Open source with a permissive license preferred.

Thank you for your contributions!
